### Bug fixes

- **The coding standard of a Nextcloud app checks only what Git keeps:** php-cs-fixer read every PHP file of the app other than those with `build` or `vendor` in their path. A tool that a project installs with npm into a folder of its own, such as `scripts/eslint/node_modules/` behind a `.gitignore` of its own, was read as well, so the second local run of `scripts/check.sh` failed the step *Coding standard* on a file of a package, such as `node_modules/flatted/php/flatted.php`. `.php-cs-fixer.dist.php` now leaves out whatever a `.gitignore` of the app ignores, wherever it lies, `vendor/` and `build/` among it. A file of the app with `build` or `vendor` in its path, such as `lib/Command/Rebuild.php`, which was left out before, is checked now; run `vendor/bin/php-cs-fixer fix` once if the step finds one after the update ([#792](https://github.com/Dennis-Otto/repo-blueprint/issues/792)).
