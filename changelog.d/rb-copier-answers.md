### Bug fixes

- **Copier refuses answers that would break a file, and a new repository links its website and has topics:** a description with `"""`, `*/` or `]]>` ended the docstring of a Python package, the comment of a Node package or the CDATA of `appinfo/info.xml` early, a backslash started an escape, `$HOME` in a label of the `Dockerfile` became a folder of the build, and the id of a Nextcloud app taken from a long name was longer than the 32 characters that the App Store takes. Now Copier says at the question what a name or a description can't hold, the `Dockerfile` keeps every `$`, a quote may end the description, and the id of an app follows the App Store, its default cut to 32 characters; topics follow GitHub's rules. The homepage is the website that the Docs workflow publishes, unless you name another or none: the README shows a badge and a link to it, `settings apply` puts it in the About box, an integration names it as its documentation, and `appinfo/info.xml` of an app as its documentation and website, with its discussions and its sponsor. Each kind starts with topics of its own, so a new integration passes the check *hacs* with the default answers, and its checklist shows whether the description and the topics are on GitHub. A new Nextcloud app analyzes its JavaScript with CodeQL. An existing repository keeps the answers that the new questions take; an answer that they refuse, the update replaces with the default, so an integration without topics gets those of its kind. A name or a description with these characters has no default: answer it anew with `copier update --defaults --vcs-ref=:current: --data description=...` before the blueprint bot can update the repository. To link its website, answer it with `copier update --defaults --vcs-ref=:current: --data homepage=https://OWNER.github.io/NAME/`, and add the badge to its README, which is the project's. A template of the blueprint that replaces a text of one of its workflows now fails when the text is gone, instead of leaving the blueprint's own values in every repository.
