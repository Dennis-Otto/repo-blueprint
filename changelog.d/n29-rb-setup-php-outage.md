### Bug fixes

- **The release of a Nextcloud app no longer fails in an outage of GitHub's downloads:** the build of the release set up PHP 8.4, which the runner doesn't have, so setup-php downloaded it and Composer from the pages of releases on github.com without a token, and its mirrors are blocked in that job. When those downloads failed, as on 8 November 2026, the release stayed a draft until its build ran again. The build now signs the app on PHP 8.3, which Nextcloud 35 runs on and which the runner already has, together with its Composer, so it downloads neither. The token of the build also no longer lands in Composer's `auth.json`, where the project's own steps of the build could read it ([#800](https://github.com/Dennis-Otto/repo-blueprint/issues/800)).
