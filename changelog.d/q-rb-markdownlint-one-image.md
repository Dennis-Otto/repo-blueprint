### Bug fixes

- **The check *lint* and `scripts/check.sh` lint the Markdown with one version of markdownlint-cli2:** the check *lint* ran it through `DavidAnson/markdownlint-cli2-action`, while `scripts/markdownlint.sh` runs its image, and Renovate moved the image on its own whenever no release of the action ran the new version, as with 0.24.1, so that a document could pass one and fail the other. The check now runs the same image itself, by the tag and digest of `scripts/markdownlint.sh`, as it runs actionlint and REUSE, and Renovate moves it in both files in one pull request that merges by itself. Each finding still shows on its line of a pull request, and the fix bot still fixes what markdownlint can fix. After the update, the next pull request of Renovate for markdownlint-cli2 brings both files to the newest version; `DavidAnson/markdownlint-cli2-action` leaves the allowed actions of `.github/repository.toml`.
