### Features

- **The screenshot bot can leave slow hosts out of its wait, give the script a time limit and keep what a failed render left:** `.github/screenshots.toml` can set three more keys. `skip_wait`, such as `["launchpad.net:443"]`, names hosts of `hosts` that the jobs don't wait for before the script runs, such as one that often keeps a runner waiting and that the script needs only later; the jobs still allow them. `timeout_minutes`, such as `21`, gives the script a time limit of 1 to 45 minutes in place of the hour of the job, and the script itself gets the signal with which GitHub ends it, so that it can stop its demo and say where it waited. `failure_folder`, such as `"tests/e2e/artifacts"`, is a folder that a failed shard keeps as the artifact `failed-render-<shard>-attempt-<attempt>` for seven days, for you to see what went wrong. The render still has no secrets, and the pull request never takes that folder ([#693](https://github.com/Dennis-Otto/repo-blueprint/issues/693)).

### Bug fixes

- **A job no longer waits two minutes for a host on another port than 443:** a job behind Harden-Runner asked each of its hosts on port 443 before its first step, also one that it may reach only on another port, such as a mirror of apt on port 80, and so waited two minutes and warned on every run. It now asks each host on its own port, by HTTP on 80 and by HTTPS on any other, and a host that answers at all counts as reachable ([#693](https://github.com/Dennis-Otto/repo-blueprint/issues/693)).
