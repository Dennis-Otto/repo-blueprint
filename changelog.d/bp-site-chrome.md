### Features

- **Every website leads to its owner and asks GitHub for nothing:** the footer of every page now links to the owner's profile on GitHub, to the owner's website with all of their projects, for a website under it such as `https://owner.github.io/demo/`, and to GitHub Sponsors when `.github/FUNDING.yml` names an account, in the language of the page; the owner's own website gets no link to itself. A list `extra.social` in your `mkdocs.yml` takes their place, and `extra.social: []` shows none. The header shows the version of the latest stable release, read from the release manifest or git when the website is built, already on the build of the release itself, in place of the stars and forks that Material had every reader's browser fetch from the API of GitHub: that request failed with a 404 and an error in the console on a website without a release and with a 403 on networks that many people share. `blueprint.py site-check` fails a website whose pages would still ask GitHub. The update brings all of this.
