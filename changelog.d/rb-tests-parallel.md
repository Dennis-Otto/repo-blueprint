### Performance

- **The tests of Python projects run on every core:** `scripts/check.sh` ran them one after the other, so a Home Assistant integration with 1700 tests spent minutes of its required check on one core of four. Now it runs them with pytest-xdist on every core, and pytest-cov brings the coverage of each process together, so `fail_under` and the coverage report stay as they were; where pytest-xdist or pytest-cov is missing, the tests run one after the other as before. Home Assistant integrations have both already, and new Python projects get them with pytest-timeout in `requirements-dev.txt`, with a limit of 30 seconds for each test. An existing Python project takes them by adding `pytest-cov`, `pytest-timeout` and `pytest-xdist` to `requirements-dev.in`, compiling `requirements-dev.txt` again with the command in its header and, for the limit, `timeout = 30` under `[tool.pytest.ini_options]` in `pyproject.toml`. `PYTEST_XDIST_AUTO_NUM_WORKERS` sets the number of processes, such as fewer on a machine with many cores and little memory.
