### Features

- **Pages in one column, so that they read well on a phone and in the GitHub app:** the GitHub app keeps an HTML table that sets text beside a picture, and squeezes it into narrow columns with a strip of text and a tiny picture. `scripts/check.sh` now fails on such a table and on a cell with a width, such as `<td width="55%">`, in a README, a CONTRIBUTING file or a page of `docs/`; each finding names its file and line and says how to fix it, and in the CI the pull request shows it at that line. `python3 .github/blueprint.py pages --fix` fixes them for you: it puts the cells of a layout table one below the other, the text before its picture and each caption before its picture, and leaves out the widths of cells. CONTRIBUTING.md describes the convention: tables for tabular data alone, pictures and GIFs at full width below the text that they illustrate, and long lists in `<details>`. A repository whose pages lay out pictures in tables fails the check after this update; `python3 .github/blueprint.py pages --fix` and a commit make it pass.
