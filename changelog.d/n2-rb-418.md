### Features

- **The accessibility check looks at every page as a phone shows it:** the check *docs* now opens each page at 375 px wide as well as at 1280 px, in both schemes, and runs axe-core on the layout that CSS switches to on a narrow screen. A page that scrolls sideways at that width fails the check under the rule `reflow` (WCAG 1.4.10), which names the widest element that overflows and how to fix it: let it wrap, or put it in a frame that scrolls on its own. `.github/a11y-accepted.toml` accepts it like any other rule. A run of every page takes about twice as long, so the limit of the step rises to 30 minutes and that of the job to 35. None of the websites made with the blueprint scrolls sideways today, so nothing changes for a repository unless a page does.

### Bug fixes

- **A table that scrolls on a phone takes the focus:** on a narrow screen, the frame that Material puts around a wide table scrolled, but a reader with a keyboard couldn't reach it. The script of every website now gives it the focus once it scrolls, and does the same for a block of code. It also sees a phone that turns and a fold that opens.
