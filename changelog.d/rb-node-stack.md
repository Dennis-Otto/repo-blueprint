### Features

- **A Node package lints and formats its code with Biome, shows its coverage in the report of the PR coach, and installs without the scripts of its packages:** the new step *Lint and format* of `scripts/check.sh` runs `npx biome ci --error-on-warnings .` with the recommended rules, sorted imports and the indentation of `.editorconfig`, from the new `biome.jsonc`, which leaves out the files of the blueprint in `.github/`; each finding is an annotation at its line in the CI, the fix bot runs `npx biome check --write .` on a pull request whose check fails, and the dev container gets the extension of Biome. `npm test` writes the LCOV report `lcov.info` beside its usual output, the CI keeps it as the artifact `coverage`, and the PR coach and the dashboard read it as they read the `coverage.xml` of the other kinds, so a Node package now gets the coverage of each file against that of `main`. The dev container, `CONTRIBUTING.md` and `AGENTS.md` install with `npm ci --ignore-scripts`, as the CI does, so no package runs code of its own as it installs, and `.editorconfig` indents JSONC files with two spaces, as they are written. `package.json` belongs to the project, so an existing Node package turns the new parts on itself: `npm install --save-dev @biomejs/biome` adds Biome, and the step runs from then on (until then it says so and passes); `npx biome check --write .` brings the code into its format once; and `--test-reporter=spec --test-reporter-destination=stdout --test-reporter=lcov --test-reporter-destination=lcov.info` in the script `test` writes the report.
