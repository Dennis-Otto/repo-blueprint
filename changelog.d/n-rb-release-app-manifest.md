### Features

- **One command registers the release app:** `python3 .github/blueprint.py app register` replaces the eight manual steps of a new owner. You confirm one page on GitHub, which creates the app from a manifest with all of its permissions, *Variables* included, which the old link couldn't fill in. The command then sets the private key as the secret of the environment `release` without writing it to a file, names the app in a pull request, so that no value is copied by hand, and prints the link that installs it. `app connect --key-file FILE` does the same for an app that exists, such as for a further repository of the owner. The checklist now names the command in place of the long link, and it ticks the installation off once GitHub shows a check suite of the app on `main`. An existing repository has nothing to do.
