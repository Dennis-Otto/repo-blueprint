### Features

- The blueprint releases at most once a day. Its release bot merges the release pull request in its daily run at 02:25 UTC once the checks pass, so each repository that follows the blueprint gets at most one update pull request a day, in the night of Europe. The release pull request says in a comment when it goes. A fix that can't wait still goes at once: start the workflow *Release* by hand (`gh workflow run release.yml`). A fix of a vulnerability that Renovate marks with `[security]` goes at once by itself.
- A repository can choose the same with `RELEASE_MERGE = "daily"` under `[variables]` of `.github/repository.project.toml`. Without it, the new default `RELEASE_MERGE = "maintainer"` keeps everything as it was: the maintainer merges the release pull request, and a release of nothing but dependency updates merges itself once a day. The daily run of the release bot of every repository moves from 05:25 UTC to 02:25 UTC, plus the minutes of its slot.
