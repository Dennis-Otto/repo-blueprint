### Features

- **A new repository's README shows the badge of the issue assistant:** with the answer `issue_assistant_ai`, the README of a new repository shows the badge *issues: triaged by issue assistant* among its others, as the issue assistant offers it, so that reporters know before they open an issue; without the AI, it shows none. The README belongs to the project, so an existing one keeps what it has: copy the badge from the [README of the issue assistant](https://github.com/Dennis-Otto/issue-assistant#show-that-you-use-it), and take it out again when you switch the AI off ([#683](https://github.com/Dennis-Otto/repo-blueprint/issues/683)).
