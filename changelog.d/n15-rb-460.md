### Features

- **The website lists other owners' repositories made with the blueprint:** once a week, the dashboard asks GitHub's code search for the public repositories of other owners whose `.copier-answers.yml` names the blueprint, and lists each one under *Also made with the blueprint*, with its kind and the release of the blueprint it is on, and as `dashboard/made-with.json`. A repository with the topic `repo-blueprint-unlisted` stays off the list, as does a private, archived or forked one: every run checks the list again, so the topic takes a repository off within two hours. When GitHub refuses the search, the run checks the previous list again, and the next run searches anew ([#460](https://github.com/Dennis-Otto/repo-blueprint/issues/460)).

### Bug fixes

- **A bot waits when GitHub asks it to:** a request that GitHub answers with 429 and the seconds to wait in `Retry-After`, as the code search does after a search or two in a minute, now waits that long, up to 90 seconds, and tries once more, instead of failing at once.
