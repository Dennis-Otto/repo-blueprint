### Performance

- **The CI installs its Python tools in seconds, and a step that hangs fails after five minutes:** the checks of the Python stacks, the website, the fuzzing, the property and the mutation tests install their hash-pinned tools with uv instead of pip, from a cache that GitHub keeps under a key of the lock files, and uv checks every package against its hash, also one from the cache. `check (home-assistant)` no longer spends about 50 seconds in `pip install`. mypy starts from its cache of the last run that passed and checks again only what changed; it keeps no module with an error, so the cache hides no finding. Every step that installs, builds or downloads ends after five minutes, and `check (python)`, `check (github-action)` and `check (home-assistant)` end after 8, 8 and 15 minutes instead of 15 to 20, so a step that hangs no longer holds a pull request for half an hour. The CI of a container runs Hadolint in its image, with the same rules and annotations, instead of an action that built an image of its own at the start of the job. The update brings all of this; locally, pip installs the tools as before.
