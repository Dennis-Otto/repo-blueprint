### Features

- **Pictures that renew themselves, in every repository:** the screenshots of a README, a website or a store showed a project as it was when someone last took them, and only ha-autodarts had a bot of its own. Every repository now has the screenshot bot (`screenshot-bot.yml`), which a project turns on with `scripts/screenshots.sh`, a script of its own that renders its pictures in place, and `.github/screenshots-paths.txt`, the files whose change can change them. After such a change of `main`, after every release, every week and on demand, the bot runs the script without secrets and compares each picture with the one of `main` by its pixels: a picture that looks the same keeps its file, so a new browser or encoder changes nothing. When pixels changed, one pull request from `bot/screenshots` holds the new pictures, with the share of the pixels that changed in each, and merges itself once every check passes. The bot commits nothing but pictures, as the release app, and runs nothing of the script with a token that writes. A new repository starts with a script that renders the social preview; on your machine, `python3 .github/blueprint.py screenshots restore` after the script shows which pictures really changed. The recording and the dashboard of the blueprint's own README renew themselves the same way after each release that changes what they show.
