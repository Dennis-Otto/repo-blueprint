### Bug fixes

- **A slow fall of the mutation score opens its issue:** each weekly run was compared only with the run before, so a score that lost up to half a point every week fell as far as it liked without the issue *Mutation score dropped*. `mutation.json` now carries the best score and the best score of the logic of the complete runs forward, and a run more than half a point below either opens the issue, with that best run as the run before the drop. The first run after the update compares with the run before, as until now. To accept a lower score, such as after new code with few tests, close the issue as not planned: later runs compare with the score of its latest run ([#824](https://github.com/Dennis-Otto/repo-blueprint/issues/824)).
