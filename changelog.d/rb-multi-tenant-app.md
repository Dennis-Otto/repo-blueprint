### Features

- **Any owner can use the blueprint, with a release app of their own:** a repository of another account or organization got the release app, the name and the defaults of the blueprint's owner, so its release, settings, update and branch bots could never get a token, and its license and governance named the wrong person. Copier now asks for the owner, without a default, takes the owner as the maintainer, and asks for the release app of the owner by its name, Client ID and App ID, which may stay empty at first; only the blueprint's owner gets its own app as the default, so every repository of the Rollout keeps its settings. `.github/repository.toml` names the app in the new variable `RELEASE_APP`, and without one it names none, lets no app create the release tags and asks for no private key. `blueprint.py checklist` then starts with a link that registers the app on the owner's account or organization, with its name and its permissions filled in and without a webhook, and the `copier update` that names it; once it is named, the checklist links its installation on the repository. Until then, the blueprint bot says in its summary what is missing, instead of failing at the token of the app, and the release bot warns that no release can be published. The README shows how to keep the answers of an owner in Copier's settings file, so that every new repository asks only what is new.

### Changes

- **The question of the owner has no default any more:** `copier copy --defaults` needs `--data owner=…`, or the owner in the defaults of Copier's settings file. An existing repository keeps the answers it has; its next update adds the answers of the release app: the app of the blueprint's owner for a repository of that owner, which keeps its settings, and none for another owner, whose checklist then registers one.
- **The template needs Copier 9.8 or later:** the `copier update --vcs-ref=:current:` that names the release app uses a reference Copier knows only since 9.8, so the template no longer accepts 9.4 to 9.7, where that step failed with a Git error.
