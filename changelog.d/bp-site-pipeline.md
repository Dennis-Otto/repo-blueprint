### Performance

- **The website goes live sooner, builds in seconds and publishes `.well-known`:** on `main`, the check *docs* hands the website that it built to GitHub Pages, and one more job publishes it, where a second job used to install the tools and build it again; a push reaches the website with two jobs instead of three, each of which waited for a runner. The fonts and scripts that Material downloads for the website come from a cache of the ISO week, which only a push to `main` saves, so the second build of a week takes about 1.5 seconds instead of 9 and fails no longer when Google Fonts has a hiccup; the first build of a week downloads them anew. Files and folders whose name starts with a dot, such as `.well-known/security.txt`, now reach the website. The required check keeps its name, and the update brings all of this.
