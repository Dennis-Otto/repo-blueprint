### Features

- **The release verification checks the zip that HACS installs:** for a Home Assistant integration (`PUBLISH_TO` `hacs`), `verify-release.yml` checked the signed tag, the provenance and the SBOMs, but not the one file that HACS installs. It now checks that the release has the zip that `hacs.json` names with `zip_release`, that its `manifest.json` lies at the root of the zip, with the domain of the folder in `custom_components/` and the version of the release, and that HACS offers the release as it should: a release as the latest one to every user, a beta only as a prerelease. A beta, such as 2.1.0-beta.1, now also has its own version in the `manifest.json` of its zip, which Home Assistant shows to its testers, where it had the version of the last release. Decision 0065 says why.
