### Bug fixes

- **The answers for bestpractices.dev no longer claim more than your repository holds:** the answers on the sign-off (`dco` and `osps_le_01_01`) say that every commit that a person adds to a pull request carries one, and that the check *DCO* lets through only a bot's own commits in that bot's pull request, such as a release or an update, since a bot can't sign the certificate. They also say that GitHub signs off only the commits that a person makes in its web interface. In a repository without a build (generic), `test_policy_mandated` no longer names an automated test suite, which such a repository doesn't have. `CONTRIBUTING.md` says which commits need no sign-off, and `GOVERNANCE.md` asks a sign-off of the commits of a person. The weekly issue of the bot brings the new words to your entry; save its links after the update.
