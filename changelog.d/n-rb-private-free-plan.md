### Features

- **A private repository on GitHub Free passes its checks:** `settings apply` reads whether a private repository has GitHub Code Security and, without it, sets the new variables `CODE_SCANNING` and `DEPENDENCY_REVIEW` to `off` and drops the rule of code scanning from the ruleset of `main`. CodeQL then keeps its results as the artifact `codeql-sarif`, lists them in its summary and fails on an error or a security alert of high or critical severity; zizmor fails on every finding; OSV-Scanner, the Scorecard and the taint analysis of PHP keep their findings out of code scanning; and the dependency review leaves the vulnerabilities of the lock files to OSV-Scanner. The rulesets and GitHub Pages that GitHub refuses for the plan are a notice, which fails no run, and the website of `main` is the artifact `website`. The checklist shows a private repository the step *GitHub Code Security on*, and the FAQ a table of what works on which plan (decision 0081). A public repository runs as before.
