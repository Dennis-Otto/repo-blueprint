### Features

- **The issue assistant names good first issue candidates in every repository:** its morning digest now lists the issues that someone new to the project could take, for you to confirm. The labels `good first issue` and `help wanted` move to the group `contribution` that it reads, and the issue assistant comes along in version 1.9.0, as an older one refuses that group.
- **A release can change a file of the project, and the update's pull request fixes itself:** an update never overwrites `.github/labels.toml` and the other files of a project, so a change that a release needs there used to take a person in each repository. The new step *Files of the project* of `scripts/check.sh` finds what is left to move, and the fix bot commits it onto the pull request of the update. A project that doesn't want the move of a label writes a comment behind its line `group = "decision"`. By hand: `python3 .github/blueprint.py migrate --fix`.
