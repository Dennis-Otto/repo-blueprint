### Bug fixes

- **A check no longer fails when GitHub's downloads time out for a while:** on 8 November 2026, GitHub's downloads without a token timed out for hours, and the link check of the website, the Links workflow and CodeQL failed in every repository. Every tool that the workflows download from a release on GitHub, lychee, CodeQL, gitsign, krankerl, Infection and syft, now comes through GitHub's API with the token of the job, which kept working, tries again after an error of GitHub for two and a half minutes, and is checked by its sha256; when GitHub keeps failing, the annotation says that it is an outage of GitHub and not a problem of your change. lychee comes from `.github/lychee.sh` instead of its action, with the same rules, cache and report, and CodeQL analyzes with the version that its action brings, which the runner usually has already ([#713](https://github.com/Dennis-Otto/repo-blueprint/issues/713)). The flaky-test bot asks GitHub again when it answers with an error of its own, and leaves a run alone that runs again already. `lycheeverse/lychee-action` leaves the allowed actions: a workflow of your own that still uses it runs `bash .github/lychee.sh` instead, or allows the action in `.github/repository.project.toml`.
