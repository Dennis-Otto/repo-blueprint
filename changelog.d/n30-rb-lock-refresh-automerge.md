### Features

- **The weekly refresh of the lock files merges by itself, from versions at least a week old:** the pull requests `chore(deps): lock file maintenance` and `chore(deps): refresh pip-compile outputs` used to wait for a review, piled up unmerged, and so the indirect dependencies never moved. Now the refresh of npm takes only versions released at least a week before, and after Renovate, `blueprint.py locks --refresh` compiles the lock files of pip-compile again from uploads a week old, keeping what `main` pins; both merge on their own once every check passes. The fix of a vulnerability still comes at once, as before. A new step of the check dependency-review asks PyPI and the registry of npm when each version of the refresh came out, and holds the refresh when one younger than a week comes anyway, naming each. The refresh of Composer, which can't keep to that age, waits for you on a branch of its own, `renovate/review-lock-file-maintenance`, and so does that of pip-compile with the Mend Renovate app ([#783](https://github.com/Dennis-Otto/repo-blueprint/issues/783)).
