### Features

- The issue assistant has a file of the project for the hosts that its comments may link to and the files that name its AI: `.github/issue-assistant/config.project.toml`, whose `[links] hosts` and `[transparency] files` add to those of `config.toml`, and which no update overwrites. Add a host there, such as the documentation of a service that your project uses, instead of in `config.toml`, whose next update would conflict with the change. The update creates the file with empty lists; a repository that added hosts or files to `config.toml` can move them there now, and the release after this one moves them by itself through the step *Files of the project*.
