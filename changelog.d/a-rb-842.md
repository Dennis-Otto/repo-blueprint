### Bug fixes

- **An update no longer drops a change of the repository without a word:** `copier update` merges a change of the repository line by line only into a text file that the release keeps; a file that the release deletes, renames or replaces as binary it takes from the release as it is, without conflict markers, so the repository's own change to such a file was gone, and the update pull request merged itself. The blueprint bot now renders what the blueprint made for the version before and compares each such file with it: one that the repository had changed is listed in the description under *Changes of this repository that the update drops*, with what to do, and turns auto-merge off and adds the label `merge-conflict`, as a conflict does. A file as the blueprint made it still updates by itself ([#842](https://github.com/Dennis-Otto/repo-blueprint/issues/842)).
