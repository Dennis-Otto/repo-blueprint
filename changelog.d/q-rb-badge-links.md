### Bug fixes

- The answers of your project on bestpractices.dev no longer go stale unnoticed. bestpractices.dev never replaces an answer that its entry already gives, so a changed answer of `.bestpractices.json`, such as a link to a workflow that moved, never reached the entry, and *Save (and continue)* didn't take it in either. Once a week, the run of *Links* now reads the public entry of the project whose badge your README shows, and keeps the issue *The answers on bestpractices.dev differ from .bestpractices.json* open while it differs: for each level, it gives a link of the edit page that proposes the answers of the file and forces exactly those that differ. Open each link while signed in, check the highlighted fields and save. The bot only reads the entry and needs no secret; a repository without the badge asks nothing.
