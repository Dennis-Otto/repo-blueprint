### Bug fixes

- **The Mutation run of a pull request in a Nextcloud app ends within its time and reports a score:** it ran all of Infection, which no longer fit into the 25 minutes of the job, so every such run showed as cancelled and proved nothing. Infection now changes only the files of a sample of about 600 lines of the source, the same ones each time, as mutmut tries a sample of the functions of Python, and the summary lists them; the weekly run still changes every file. Infection that runs out of its time now fails with a message of its own instead of being cancelled at the limit of the job ([#858](https://github.com/Dennis-Otto/repo-blueprint/issues/858)).
