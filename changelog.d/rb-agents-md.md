### Features

- **Coding agents follow the rules of each repository:** every repository gets an `AGENTS.md`, which Claude Code, Codex, GitHub Copilot and Cursor read: the commands that set up the tools and run the checks and tests of its kind, the titles of pull requests and the versions they make, the fragment of the changelog in `changelog.d/`, the diagrams as pictures of their sources, the sign-off, and what never to do to get a check green. It also says which files belong to the project and which to the blueprint, so that an agent changes a workflow or `scripts/check.sh` in the blueprint instead of in one repository; a test keeps that list equal to the files that an update never overwrites. `CLAUDE.md` brings `AGENTS.md` to Claude Code; the package of a Nextcloud app leaves both out. The notes of a project, such as its architecture and the commands of its own checks, go into `.github/agents.project.md`, which the update adds once and then leaves to the project. A repository that already has an `AGENTS.md` or a `CLAUDE.md` gets the blueprint's in the update pull request, with conflict markers where the two differ: move its own notes into `.github/agents.project.md`. Decision 0015 says why.
