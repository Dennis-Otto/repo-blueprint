### Bug fixes

- **The weekly clean-up keeps a branch that was just made:** it deleted every branch without a commit of its own, also one that somebody had just created from `main`, such as with *Create a branch* on an issue. Such a branch now goes only once its last commit is a day old. A branch whose name has a `#` or a `%` no longer turns the run red every week, and a branch that GitHub refuses is a warning, so the clean-up goes on with the others ([#854](https://github.com/Dennis-Otto/repo-blueprint/issues/854)).
- **An update of the blueprint gets its auto-merge after all:** when GitHub refused to turn on the auto-merge of a new pull request of the blueprint bot, every later run took that for a maintainer's decision, and the update waited for a merge by hand. The bot now asks three times, and should GitHub still refuse, its next run turns auto-merge on; an auto-merge that you turned off stays off ([#855](https://github.com/Dennis-Otto/repo-blueprint/issues/855)).
