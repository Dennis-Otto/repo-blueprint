### Bug fixes

- **A pull request can no longer post Markdown, links or mentions under the name of the coverage bot or the flaky-test bot:** the coverage bot copied the name of each file from the `coverage.xml` of a pull request into its comment as it was, so a report from a fork, which writes the names as it likes, could end the code and the table with a backtick, a pipe or a line break and add headings, links and @-mentions to the comment of the bot. Each name is now plain code on one line, which no backtick, pipe or line break of the name ends, cut at 200 characters, and an empty name shows as "(unnamed file)". Hits that are no count, such as `1.5` or `x`, count as a number or as 0 instead of stopping the bot, and a report that isn't UTF-8 ends with an error that names it. The table shows the first 100 files whose coverage changes and counts the others, so the comment always fits into one comment of GitHub, and a late run for a commit before the head of the pull request no longer replaces the comment for its head. The issue of flaky tests no longer names the branch of a fork, which a pull request names as it likes. The fuzzing of the blueprint now feeds any report to the coverage bot as well.
