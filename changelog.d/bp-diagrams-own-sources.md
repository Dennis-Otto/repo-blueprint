### Bug fixes

- **The diagrams of the blueprint leave a project's own sources alone, and their pictures keep saying what the sources say:** once a page showed one picture of a diagram, `scripts/diagrams.sh` took over every source in `docs/diagrams/`, so a repository that draws Mermaid sources there in its own way, as ha-autodarts does, failed its checks and got a picture drawn for every one of them. The script and the checks now take only the sources that a page shows and those that have a picture already. A `mermaid` example inside another block of code, such as a guide on how to write a diagram, and a block in a comment stay as they are, where `--extract` turned them into pictures; a block in a quote, such as a note of GitHub, becomes a picture as well, where the checks didn't see it. `--extract` now writes the `alt` of each picture from the `accTitle` and `accDescr` of its source and takes HTML out of the labels of the sources, and `scripts/check.sh` fails on an `alt` that its source doesn't say, so a change of a description reaches the screen readers in the GitHub app as well, also through the diagram bot. A pull request that changes only a picture is checked too. The check *diagrams* promises the diagram bot's commit only where it can make one: on a branch of the repository that has the release app.
