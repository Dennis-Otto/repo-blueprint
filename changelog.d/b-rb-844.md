### Bug fixes

- **`copier copy --defaults` no longer stops on a question that nobody answered:** for a project name that starts with a digit, such as `2FA Helper`, the defaults of the Python package, the domain of Home Assistant and the id of a Nextcloud app started with that digit and failed their own checks; they now start with `py_` or `app_`, such as `py_2fa_helper` and `app_2fa_helper`, and the namespace of a Nextcloud app with `App`. A repository name of one character is allowed, and a Nextcloud app of such a name gets an id such as `app_x` ([#844](https://github.com/Dennis-Otto/repo-blueprint/issues/844)).
- **The namespace of a new Nextcloud app keeps the capitals of its name:** the project name `PaperlessSync` gave the namespace `Paperlesssync`, and `iCal Sync` gave `IcalSync`; each word now only gets a capital first letter, which makes `PaperlessSync` and `ICalSync` ([#844](https://github.com/Dennis-Otto/repo-blueprint/issues/844)).
- **`blueprint.py` names Python 3.11 as too old before it starts:** it stopped with its message only below Python 3.11, while its tools need 3.12, so Python 3.11 got further and failed later. It now says on 3.11 too that the tools need Python 3.12 or later, and how to install it ([#844](https://github.com/Dennis-Otto/repo-blueprint/issues/844)).
- **A command that can't find the repository of the folder says why:** `blueprint.py settings`, `checklist` and the other commands that ask `gh repo view` for the repository said only that the folder is no GitHub repository the CLI knows, also when the GitHub CLI wasn't signed in or the network failed. They now show the GitHub CLI's own message, such as the hint to run `gh auth login`, before the hint to pass `--repo OWNER/NAME` ([#844](https://github.com/Dennis-Otto/repo-blueprint/issues/844)).
- **The fix bot drafts no entry of the changelog that renders as a heading, a list or a quote:** a title such as `fix: # heading`, `fix: - item`, `fix: > quote` or `fix: 1. first` became an entry that the changelog showed as that block, and the bot corrected the title `fix:: double` to `fix: : double`. A title whose words begin with a mark of Markdown or other punctuation now gets no draft and no correction, and the PR coach still suggests a title to a person ([#844](https://github.com/Dennis-Otto/repo-blueprint/issues/844)).
- **`SECURITY.md` links the decisions that it names:** the reason why the job of Scorecard only watches its traffic named "decisions 0088 and 0123", which are records of the blueprint and not of the repository that shows the file; it now links both on the blueprint's website ([#845](https://github.com/Dennis-Otto/repo-blueprint/issues/845)).

### Features

- **`blueprint.py --help` shows the commands of a person apart from the steps of the bots:** the help listed all 32 commands in one block, after a line of usage of several hundred characters, and its description named only three of them. It now lists the commands of a person, such as `create`, `doctor`, `checklist`, `settings` and `app`, in a group of their own before the steps of the bots and the workflows, with `COMMAND` in the line of usage ([#844](https://github.com/Dennis-Otto/repo-blueprint/issues/844)).
