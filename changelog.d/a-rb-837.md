### Bug fixes

- **The fix bot commits nothing that runs with rights where nobody reads its commit:** on a pull request of Renovate or another bot, on one whose auto-merge is on and on the pull request of `main` from `bot/self-heal`, which all merge without a person reading the bot's commit, the fix bot no longer commits a fix of a file that decides what a workflow runs, such as a file of `.github/` or `scripts/` or `pyproject.toml`, or that runs later with the key of the release app, such as `blueprint/`, `.github/blueprint.py` or the template. Whatever ran in the check, such as a new version of a dependency, could write those files before. The bot commits the other fixes as before and names each file that it left, with the reason, in its summary and in the pull request of `main`; the check stays red until a person commits that fix, by hand or with `/fix`. A person's own pull request without auto-merge gets every fix, as before ([#837](https://github.com/Dennis-Otto/repo-blueprint/issues/837)).
