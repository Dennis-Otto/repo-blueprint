### Bug fixes

- **A release of dependency updates merges itself beside a bot's commit that makes no release:** the daily run of the release bot held such a release for the maintainer when a bot had merged a commit between the updates that release-please makes nothing of, such as `docs: renew the pictures`, `docs: update the screenshots` or `chore: update to the blueprint v1.2.3`, which the bots merge almost every day, and the run stayed green, so nobody heard of it. Now only what can change the release counts: a release merges itself once a day when every change for users in it is a dependency update without a version of its own, and every other commit in it was made by a bot. A change of a person, of whatever type, waits for the maintainer as before, and the summary of the run says why a release waits ([#841](https://github.com/Dennis-Otto/repo-blueprint/issues/841)).
