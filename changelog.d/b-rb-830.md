### Bug fixes

- **The 404 page of a website leads on:** a wrong or an old address showed only the words "404 - Not found". The page now says that there is no page at the address, links to the home page of each language of the website and points to the search, in English and German. Because the pages end in `.html`, an address in the style of folders that people guess, such as `faq/` or `faq`, leads on to `faq.html` when that is a page. A 404 page of the project's own, in an override of the theme, stays as it is ([#830](https://github.com/Dennis-Otto/repo-blueprint/issues/830)).
- **The dashboard leads back to the website:** its first line links to the website and to the section that explains its columns, a shared link shows a preview with its description and picture, the tab shows the icon of the website, the sitemap of the website lists it, and the name of each repository stays in view while a table scrolls sideways on a phone ([#831](https://github.com/Dennis-Otto/repo-blueprint/issues/831)).
