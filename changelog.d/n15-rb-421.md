### Features

- **The screenshot bot renders in shards, commits files besides pictures and blocks the hosts that a project doesn't name:** `.github/screenshots.toml`, a file of the project, can name `shards`, which render side by side on runners of their own, each with its name in `SCREENSHOTS_SHARD`, all of them the same commit, and which the job *collect* puts together for the one pull request; `files`, files besides pictures that the script renders, such as a recording that a page plays, which the bot commits by their exact paths as text; and `hosts`, the hosts that the jobs that render may reach, of which Harden-Runner then lets through no other. Without the file, one job renders every picture, the bot takes only pictures and Harden-Runner records, as before. A due change now starts a run by hand that renders, so that the runs that render wait for each other and every shard renders the newest `main` ([decision 0120](https://github.com/Dennis-Otto/repo-blueprint/blob/main/docs/decisions/0120-the-screenshot-bot-renders-in-shards-takes-named-files-and-blocks-other-hosts.md), [#421](https://github.com/Dennis-Otto/repo-blueprint/issues/421)).
