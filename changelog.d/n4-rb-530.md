### Features

- **A Nextcloud app has an environment for the key that signs it and one for the App Store:** the settings now declare `signing`, with `APP_PRIVATE_KEY`, and `appstore`, with `APPSTORE_TOKEN`, next to `release`, which keeps both secrets and from which the workflows still take them. This prepares the release that keeps the private key of the release app out of reach of the build. After this update, the settings bot creates both environments for `main` alone, and until each secret is set there it fails and names the command: run `gh secret set APP_PRIVATE_KEY --env signing < KEY_FILE` and `gh secret set APPSTORE_TOKEN --env appstore`, with the same values as in `release`. Bot health keeps one issue with the label `bot-failure` open in each repository until then, and the next Settings run that passes closes it.
