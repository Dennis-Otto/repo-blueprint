### Bug fixes

- **A private repository no longer hears of a social preview that nobody sees:** GitHub shows the social preview only for a public repository, and takes a new upload in a private one only where someone uploaded one before. The nightly look of the bot-health bot of a private repository opened the issue *Upload the new social preview* all the same, and tried to download an upload that GitHub may serve to nobody without a token, which would have failed the look every night. Now it compares nothing there, says why in its summary, and closes such an issue as not planned; the checklist's step *Social preview uploaded and current* stays neutral, with the reason. Once the repository is public, both compare the upload with `.github/social-preview.png` again ([#760](https://github.com/Dennis-Otto/repo-blueprint/issues/760)).
