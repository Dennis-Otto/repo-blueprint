### Bug fixes

- **The bots of pull requests keep working after GitHub blocks `pull_request_target` on 2 December 2026:** from that day, GitHub blocks every workflow that starts on `pull_request_target` in a public repository, unless an Actions event policy allows it, as it already did for two hours on 9 November 2026. The title check, whose check *conventional title* every pull request needs, the area labels, the welcome, the branch bot, the auto-merge of Dependabot's updates and the issue lifecycle would no longer start, and no pull request could merge. The settings bot now keeps the policy *Allow pull_request_target* in every repository, which lets exactly these workflows start on the event, each with its other events, and no other workflow; `pull_request_target` of `[actions]` in `.github/repository.toml` lists them. `settings check` and the check *lint* of every pull request name a workflow on the event that the list lacks: start it on `pull_request`, or add it to `.github/repository.project.toml` when it needs a token that writes for a pull request of a fork. A pull request of a fork gets everything as before ([#777](https://github.com/Dennis-Otto/repo-blueprint/issues/777)).
