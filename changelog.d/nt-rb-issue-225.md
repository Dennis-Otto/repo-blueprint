### Features

- **A version changed by hand fixes itself:** when the step *Version* of `scripts/check.sh` finds a file with another version than `.release-please-manifest.json`, the fix bot writes the version of the release bot back at its place and commits it, and nothing else of the file changes. On your machine, `python3 .github/blueprint.py fix version` does the same.
- **A lock file that Composer or npm refuses locks itself again:** after a change of `composer.json` or `package.json` by hand, `composer install` and `npm ci` stop at the lock file that no longer agrees. The fix bot now locks it again with the least change, `composer update --minimal-changes` or `npm install --package-lock-only`, which keeps every other package at its version, and commits it; a lock file that the tool takes stays as Renovate wrote it. A Node package gets the step *Package lock*, which finds such a lock file on your machine too.
- **The label `no-bot-fixes` comes with a new repository:** it keeps the fix bot away from a pull request. An existing repository adds it to its own `.github/labels.toml`, with the group `decision`.
- **The explanation of the check *reuse* says what it really finds:** `REUSE.toml` gives every file the license of the project, so a failure is a header of a file's own, with a license whose text `LICENSES/` lacks or one that no file names, and the PR coach now says how to fix that. Decision 0069 says why no command fixes it, and which fixers follow in Dennis-Otto/repo-blueprint#429.
