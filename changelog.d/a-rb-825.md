### Features

- **The path of a new owner says how to set up commit signing, which `main` requires:** the quick start, the page for your own account and the guide name a key that signs every commit among what you need, and the troubleshooting has a section of its own, *A commit has no verified signature*, with the set-up of an SSH key in a few lines and how to sign the commits of a branch again. The preflight of `create`, `doctor` and `app register` warns, without stopping, when Git signs no commit, signs only with `--gpg-sign`, or signs with SSH but names no key, and links that section, as the checklist does. The fix that the PR coach shows for the check *signed commits* now rebases with `--force-rebase`, so that it signs the commits of a branch that starts from the newest commit of its base already, where a plain rebase left them unsigned ([#825](https://github.com/Dennis-Otto/repo-blueprint/issues/825)).
