### Bug fixes

- **Biome of a Node package leaves out the diagrams that `scripts/diagrams.sh` draws:** `biome ci` in the step *Lint and format* failed on every drawn picture, for code that Mermaid writes and that the next drawing writes again. A project can now delete its own `docs/images/diagrams/biome.jsonc` and the line for it in `exclude_docs` of `mkdocs.yml`.
- **A release pull request of a Chrome extension passes Biome:** release-please puts each item of an array in `extension/manifest.json` on a line of its own, where Biome wanted a short array on one line, so `biome ci` failed on every release pull request. `biome.jsonc` now keeps the manifest in the format of release-please, and a project can delete an `extension/biome.jsonc` that did only this.
- **Stylesheets and HTML are indented like the scripts beside them:** `.editorconfig` gave CSS and HTML four spaces and scripts two, and Biome formats CSS with the setting of `.editorconfig`. Both now have two spaces, as the stylesheets of the blueprint have. `npx --no -- biome check --write .`, which the fix bot runs too, brings the stylesheets of a Node package and a manifest that has seen no release into this format.
