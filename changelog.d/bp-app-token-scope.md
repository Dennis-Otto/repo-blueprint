### Security

- **The settings bot no longer gets every permission of the release app:** its token asks only for what `settings apply` needs, *Administration*, *Issues*, *Pages* and *Variables* (read and write) and *Actions*, *Contents* and *Environments* (read), so it can neither push a commit nor change a workflow. A release app that lacks one of them fails the run at the token, whose summary says which permissions to grant and accept; one registered with the link of the checklist has them all once *Variables* is set by hand.
- **Administrators no longer bypass the rules of an environment:** the settings bot turns off *Allow administrators to bypass configured protection rules* on every environment of the settings, such as `release`, so that its private key reaches only a workflow on `main`. `settings check` names an environment that still allows it as `environment <name>.can_admins_bypass` (decision 0075).
