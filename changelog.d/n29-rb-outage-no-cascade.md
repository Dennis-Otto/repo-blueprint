### Bug fixes

- **An outage of GitHub no longer makes every bot fail and mail you:** on 9 November 2026, GitHub ended every run for five minutes before its first job, and each of those runs started the bots that follow it, which failed too: over a hundred mails in five minutes, and the bot-health bot opened issues about runs that never ran. A bot that follows the end of a run now does nothing for a run that GitHub couldn't start, with a notice instead of an issue, a second try or a move of the branch bot's line; the bot-health bot's daily look runs such a run of `main` again once. Every call of GitHub's API by the bots tries again after an error of GitHub, three times, 10, 20 and 40 seconds apart, and a bot that GitHub keeps failing ends with the notice *GitHub is unavailable* instead of a failure, as its next run catches up. A refusal, such as a missing permission, still fails the bot ([#782](https://github.com/Dennis-Otto/repo-blueprint/issues/782)).
