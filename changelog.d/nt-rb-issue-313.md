### Bug fixes

- **The check *renovate rules* explains its failure:** in a repository that runs Renovate itself (`renovate_runner` `self`), and in the blueprint, a pull request that changes the rules of Renovate or a lock file runs the check *renovate rules*, which failed with no more than the annotations of Renovate. Now it says, like every other check, what Renovate refused, why that stops updates and how to fix it, with the commands that run the same checks with Docker on your machine, in its summary and in the comment of the PR coach, also on a pull request from a fork. The troubleshooting page has a section for it.
