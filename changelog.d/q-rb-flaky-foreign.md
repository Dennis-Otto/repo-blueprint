### Bug fixes

- **The issue of flaky tests no longer opens for a failure outside your code:** a job that failed at first in an action of another repository, such as an upload of GitHub's artifact service that timed out, in a post step, in the set-up of the job or in a runner that hung after its work, and that passed when it ran again, gets no row: a notice of the run and the section *Outside the code* of its summary name it. A failure in a test, in a step of `scripts/check.sh`, in a command of your own or in a finding keeps its row, also next to such a failure, and a foreign failure that comes back for the third time in 7 days gets a row with `outside the code`, since a cause that stays is yours to fix. An open issue of an older bot whose rows all failed outside the code closes by itself on the next run of the report. The PR coach's explanation of a check no longer keeps the row of a check that GitHub kept failing or of a job that only sums up others.
- **An upload of an artifact in a required check tries once more:** GitHub's artifact client tries no network error again, so each upload tries a second time half a minute later. When only a report reads the artifact, such as the coverage report, the website of a pull request or the report of the taint analysis, a second failure warns and the check passes. For a workflow of your own, give the upload an `id`, `continue-on-error: true` and a `timeout-minutes`, then a step `sleep 30` and the same upload with `overwrite: true`, both with `if: always() && steps.<id>.outcome == 'failure'` (the same status function as the first try).
- **For a workflow of your own:** a job that only sums up the jobs that it needs writes the words `this job only sums up the jobs that it needs` in its error, as *variants* does, or else its exit keeps a row next to the job that failed; and a copy of the step *Explain the failure* passes when `blueprint.py` isn't there, as after a checkout that failed, with the line `[[ -f "$script" ]] || { echo "No blueprint.py: the checkout failed, so the PR coach has nothing to explain."; exit 0; }` before `coach explain`.
