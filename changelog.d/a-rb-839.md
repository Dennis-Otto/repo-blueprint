### Security

- **Chrome for Testing comes only from Google's storage:** `scripts/chrome-for-testing.sh` of a Chrome extension takes from Google's list of the last good builds only a version of four numbers, such as `157.0.8103.50`, and an address that starts with `https://storage.googleapis.com/chrome-for-testing-public/`. A broken or tampered list fails the check with a clear message, before the script deletes the folder of an older download or downloads and runs anything; before, a version such as `../..` pointed its `rm -rf` at a folder outside the downloads, and any address was downloaded and run as the browser ([#839](https://github.com/Dennis-Otto/repo-blueprint/issues/839)).
