### Features

- `scripts/check.sh` now lints the Markdown of every document in a step of its own, *Markdown*, with the same version of markdownlint-cli2, the same files and the same rules as the check *lint*, so a pull request that passes the checks and the hook before a push on your machine no longer fails *lint* on a heading or a list. It runs with Node 22 or newer, or with Docker, and needs the network only until the tool is there; without either, it says so and leaves the Markdown to the CI. `bash scripts/markdownlint.sh --fix` fixes what markdownlint can fix.
