### Bug fixes

- The fix bot takes a fix only where its check writes: each explanation of `.github/checks.toml` names in `writes` the paths that its commands fix, such as `**/*.md` for markdownlint or `**/*.py` for Ruff, and a file of the artifact `fixes-<name>` that the check `<name>` doesn't name stays with a person, with the reason in the summary. So whatever else runs in a check, such as a new version of a dependency, can no longer bring other files onto a pull request of Renovate, one whose auto-merge is on, or that of `main`. A check of your own in `.github/checks.project.toml` without `writes` still gets its fixes onto a pull request whose author reads the commit, but no longer onto those: give it `writes = ["**/*.ts"]`, or the globs of whatever its commands fix, as the comments of the starter of `.github/checks.project.toml` show. Where the author reads the commit, a commit of the bot that changes a file that decides what a workflow runs says so in its message and in the summary.
