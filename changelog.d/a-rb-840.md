### Bug fixes

- A new Chrome extension type-checks a popup, an options page and a content script with the `tsconfig.json` of the blueprint: it knows the DOM and the calls of `chrome.*`, by the types of `@types/chrome`, which the extension's `package.json` now has, and it compiles a content script, a file that imports and exports nothing, without the `export {}` that Chrome can't run. The update brings the new `tsconfig.json` to an existing extension; `package.json` belongs to the project, so add the types there yourself with `npm install --save-dev --ignore-scripts @types/chrome`.
