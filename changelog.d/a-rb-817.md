### Bug fixes

- **A pull request of Renovate that a merge by hand left behind gets back onto its automatic path:** after a merge of `main` with *Update branch*, Renovate took its branch for edited and left it alone for good, so a refresh of the lock files that would merge by itself, such as one that Renovate opened before the release with decision 0137, stayed open and behind `main`, and nothing said so. The nightly look of the bot-health bot now ticks the box for a rebase of such a pull request where the commits that aren't Renovate's are merges of the base or commits of bots, and Renovate builds the branch anew in its next run, so the refresh pull requests that a merge parked before come back by themselves once a repository takes this release. A change of a person on such a branch, which the new branch would drop, goes into one issue, *Renovate leaves pull requests alone*, with the label `bot-failure`. The job *sweep* of `bot-health.yml` needs `pull-requests: write` for it ([#817](https://github.com/Dennis-Otto/repo-blueprint/issues/817)).
