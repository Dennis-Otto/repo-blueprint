### Bug fixes

- **The diagram bot keeps its pull request current when `main` changes a workflow, and says when it can't help:** the Diagrams workflow moves the branch `bot/diagrams` of its open pull request to a commit on the newest `main`, and GitHub refused that move when `main` had changed a workflow since, as every update of the blueprint does. The bot then failed every week and never fixed `main`, until a person closed its pull request. Its token may now move the branch across changes of workflows, while its commit still holds only diagrams and pages, and the branch on which it makes the commit starts anew in every run, so that one which a failed run left behind can't stop the next. In a repository without the release app, the run now warns that no bot opens the pull request and names the command that fixes `main`, where it found the diagrams and said nothing. When the diagram bot can't commit onto a pull request, it now says so in a comment, with the command, where the check promised its commit and nothing came. The CONTRIBUTING.md of every repository now names the colors of the diagrams, and that a diagram in a README with a German twin comes in both languages.
