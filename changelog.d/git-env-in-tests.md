### Bug fixes

- **The checks before a push no longer let a test commit into your repository:** in a worktree, Git hands the hook before a push `GIT_DIR`, and every `git` of the checks followed it, also `git init` and the commits of a test in a throwaway repository of its own. Such a test reinitialised the repository that ran the checks, rewrote its configuration, such as `core.filemode`, and committed to its branch. The hook now lets the checks find the repository from its folder, as they do without the hook, and keeps the variables only where they alone find it, as for a worktree in a container. Since an agent sets them for the checks in a container as well, `AGENTS.md` and `CONTRIBUTING.md` now say that a test that makes a Git repository of its own first clears them, with `unset $(git rev-parse --local-env-vars)` in a shell script. The tests of your project are yours and the update leaves them alone: give each test that runs `git init` that line, or in Python an environment without the variables.
