### Features

- An existing repository that takes the blueprint runs `python3 .github/blueprint.py adopt` after `copier copy`: it writes the version of the latest release into `.release-please-manifest.json` (and `version.txt`), starts `CHANGELOG.md` with `## Unreleased`, adds the labels of the bots that `.github/labels.toml` lacks and lists the workflows that the blueprint doesn't bring, after a preflight that checks the repository on GitHub first. `--dry-run` shows what it would write.
