### Features

- **Renovate for the repositories of every owner:** Renovate ran only from the blueprint's own repository, for the repositories of its owner, so a repository of any other owner never got an update. The new answer `renovate_runner` decides who runs it: the blueprint's owner keeps the Renovate workflow of the blueprint, `hub`; every other owner gets `self`, a Renovate workflow in the repository itself, the same as the blueprint's, with the same Renovate, which runs it every two hours as the release app, for that repository alone; or answers `mend` and installs the Mend Renovate app. A run without the release app says in its summary what is missing, and `blueprint.py checklist` ticks Renovate off once its issue *Dependency dashboard* is open, with the steps for each answer until then. The settings of the bot in `.github/renovate-global.json5` no longer name the blueprint's owner: the workflow takes the bot user of the release app and the author of its commits from the token of the app.
- **The issue assistant without AI:** the new answer `issue_assistant_ai` set to no switches the AI of the issue assistant off with the variable `ISSUE_ASSISTANT_AI`, asks for no secret of the AI in the environment `issue-assistant`, and has `SUPPORT.md` say that no AI reads the issues, so the checklist passes without a token of Claude. Labels, reminders, closing and the commands of the maintainer work as before.
- **A page for your own account:** the website has a new page, *Your own account*, that walks through a repository of another owner, from the copy and the release app to Renovate, the issue assistant and the checklist.
