### Bug fixes

- **An update of npm that only moves the lock file commits only the lock file again:** since Renovate runs `blueprint.py npm-overrides --fix` after every update of npm, such an update also committed the `package.json` in which npm had saved the new version, or added a package to `dependencies`, beside a lock file whose root still had the old ranges, so that the two disagreed. Renovate now names its updates to the command in a data file: each `package.json` whose updates only move its lock file goes back to what Git keeps, and npm writes each lock file anew whose root differs from its `package.json`, but only when that brings no version that the update's lock file lacked; otherwise the update fails with a message. An update that bumps a range keeps the `package.json` that Renovate wrote, and an override that is no longer needed still leaves.
