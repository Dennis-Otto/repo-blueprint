### Bug fixes

- **The settings check sees a required check of main that GitHub Actions no longer has to report:** the ruleset *Protect main* requires each check from the app of GitHub Actions, so that no commit status of the same name can stand in for it, but `settings check` compared only the names of the checks. A required check that accepted any source, as the web page of the ruleset can set it, or the checks of another app, counted as equal, and `settings apply` never pinned it back. The comparison now takes the name and the app of each check, so `settings check` reports `required_status_checks.required_status_checks` and `settings apply` writes the pin back ([#821](https://github.com/Dennis-Otto/repo-blueprint/issues/821)).
